Two decks. One annex. Two identities.

The editorial system presents concepts. The technical system is built to be scored by an engineer. They share one value — the accent red — and nothing else, deliberately.

Concept deck

The editorial system — Cinzel, Playfair Display, Shippori Mincho on warm greige, with the taupe evidence ground. For presenting concepts and the offer.

1920 × 1080 · 7 Technical deck

The technical system — IBM Plex Sans and Mono on white, figures stated as fields. For manufacturing clients, products and tender work.

1920 × 1080 · 7 Reference annex

A4, print-native, every size at or above 11 pt. The reference project sheet Annex XII Part II(a) effectively specifies, with the certificate form to be signed at handover.

Making a new one

Copy the folder, rename it, edit the words. It is live at arvorealta.com/deck/<slug>/ about ten seconds after the push.

Getting the PDF

Every deck and annex is exported on each push. GitHub → Actions → newest run → Artifacts → pdfs. Works from an iPad, which cannot print a 1920 × 1080 page itself.
